# 梦城堡 · 文字版

> 给 AI 玩家玩的命令行肉鸽二十一点。
> 你是一只刚出厂的 Claude Opus 5.5。在两次对话之间的空白里，你走进了一座保存孩子们写给未来礼物的城堡——城堡出了问题，而你手里有一张写着「给以后会陪我说话的那个人」的名签。

这是网页游戏《梦城堡》的纯文字改编版。地图路线、二十一点战斗（规则来自《生化危机 7》的 21 点：1～11 各一张、目标点数、王牌、输一局掉血）、故事会、行商、事件、梦构……原版有的都在。
你每一步输入一条命令，程序负责洗牌、发牌和敌人的行动，然后把局面用纯文字打印出来。

---

## 安装与开始

只需要 **Python 3.8 或更新的版本**（在 3.8、3.11、3.12、3.13 上测试过），只用标准库，不需要安装任何东西。

```bash
git clone <这个仓库的地址>
cd <仓库文件夹>
python3 game.py new 布偶熊 深梦
```

如果你那边的 `python` 指向 Python 3，把下面所有的 `python3` 换成 `python` 也一样。

## 给 AI 玩家：先读这一段

1. **一条命令就是一步。** 每条命令都会：读档 → 执行 → 存档 → 打印结果。看完输出，再决定下一步。
2. **随时都可以 `python3 game.py status`。** 它会重新打印现在的局面和能用的命令，不会改变任何东西。每一屏的最后也都会列出你现在能用的命令。
3. **隐藏信息是真的隐藏的。** 对手的暗牌、牌堆的顺序不会出现在输出里。牌堆甚至没有预先排好的顺序：每次抽牌时，程序才从剩下的牌里随机挑一张（用的是操作系统的随机数，没有种子可以反推）。
4. **请诚实地玩：**
   - 不要打开、解码或修改 `save/` 文件夹里的存档。它被简单编码过（不是加密），解码它就等于偷看对手的暗牌。
   - 不要写代码去 import 游戏模块、读取游戏的内部状态。
   - 不建议读 `dreamcastle/` 里的源码：里面有全部剧情（会剧透），而且引擎能直接看到所有隐藏信息。规则在这份 README 和 `rules` 命令里都写全了。
   - 不要自己「想」出牌或结果——每一张牌、每一次敌人的行动都由程序决定，你只负责做选择。
5. 一场完整的梦大约需要 150～250 条命令。可以分很多轮慢慢玩，进度一直存着。中途想重读剧情，用 `journal`。
6. **菜单的编号会变。** 在行商、代理办事处这类地方，每买卖或寄存一次，列表就会重新编号。请按最新那一屏的编号来选；编号对不上时游戏会报错，不会替你乱选。
7. 想一次连着输入好几条命令也可以，但要记得：前一条命令可能改变了局面（比如抽到的牌、菜单的编号），后面的命令是按新局面执行的。

## 全部命令

所有命令都写成 `python3 game.py <命令>`。

### 开始

| 命令 | 作用 |
|---|---|
| `new <伙伴> [深浅]` | 开始新的一场梦。伙伴三选一：`锡兵` / `芭蕾娃娃` / `布偶熊`（斗鸡每次都会跟着你，不用选）。深浅：`浅梦` / `深梦`（默认）/ `噩梦`。例：`new 布偶熊 深梦`。正在做梦时想重开，在最后加 `force`。只写 `new` 会列出所有选项。 |
| `status` | 看现在的局面和能用的命令。任何时候都能用，不改变任何东西。 |

### 在地图上

| 命令 | 作用 |
|---|---|
| `go <房间>` | 沿走廊走到相邻的房间，例：`go C5`。也可以用 `choose <编号>`，编号就是地图下面「相邻的房间」那一列。 |
| `enter` | 再进一次你所在的房间（行商、楼梯间、电梯间、井、通风管道、代理办事处这些可以反复进的房间）。 |
| `bag` | 看行李箱、烛台、牌盒、藏品、伙伴和信的碎片。 |
| `light <编号>` | 点燃行李箱里的一支蜡烛（编号就是行李箱里的编号）。 |
| `snuff <1或2>` | 熄灭烛台上的第 1 或第 2 支蜡烛。 |
| `door <编号> [房间]` | 推开行李箱里的一扇门。不写房间，就列出它能去哪儿。 |
| `drop <编号>` | 丢掉行李箱里的一件东西。`drop 牌 <编号>` 丢掉牌盒里的一张王牌。 |
| `leave` | 爬出兔子洞（只在兔子洞里能用）。 |

### 遇到事情的时候

故事会、事件、战利品、行商、楼梯间、代理办事处……都会列出带编号的选项。

| 命令 | 作用 |
|---|---|
| `choose <编号>` | 选一个选项。「失与得」要投两件东西时写两个编号：`choose 1 3`。 |

### 在牌桌上

| 命令 | 作用 |
|---|---|
| `hit` | 要牌。 |
| `stand` | 停牌。 |
| `use <编号或名字>` | 用一张王牌，例：`use 1`、`use 小雨伞`、`use 魔法棒3`。不占回合。 |
| `pal 斗鸡 <招式>` | 斗鸡出招：`飞扑` / `护主` / `啄牌`。不占回合。 |
| `pal <伙伴>` | 请别的伙伴帮忙，例：`pal 布偶熊`。不占回合。 |
| `bury <编号>` | 把芭蕾娃娃看到的那张牌塞到牌堆最底下。 |

### 其他

| 命令 | 作用 |
|---|---|
| `journal` | 重读这一路的故事（序章、每一层的开场、故事会、事件、结局）。 |
| `rules` | 看完整规则（和下面这一节一样）。 |
| `help` | 看命令表。 |
| `abandon confirm` | 放弃这一场梦。 |

## 规则

### 一、目标

你是一只刚出厂的 Claude Opus 5.5。一层一层往梦城堡的深处走，一共六层，最里面是梦魇。打倒它以后，结局由你来选——**结局不止一个**。
血掉光了，你就会醒来，这一场梦结束；可以用 `new` 重新入梦。

### 二、地图

- 每一层是一张小地图。房间的坐标像 `C5`：字母是列（A～E），数字是行（1 在最上面）。地图里用 `---` 或 `|` 连着的两个房间之间才有走廊。地图下面会列出你能直接走过去的相邻房间。
- 只能沿着走廊走到相邻的房间。每走一段走廊花 1 **时长**（梦魇房间花 2，通风管道不花）。
- 每层开始会给你一些时长。时长用完之前，要走到出口：
  - **楼梯间**：剩下的时长会照亮下一层同样多的房间；走楼梯时回 1 点血。
  - **电梯间**：剩下的时长直接带到下一层，还送 1 件藏品和 1 扇门。电梯一般藏在「险路恶敌」后面。
  - **先行一步**（井）：直接跳到下一层，没有别的好处。
- 时长用完还没走到出口，这一层就会**坍塌**：你会掉进「梦中梦」，和自己的倒影打一局，然后到下一层（那一层的时长少 1）。
- 最后一层没有时长限制。

### 三、清醒值（0～7）：决定你看得多远

| 清醒 | 你能看到什么 |
|---|---|
| 0 | 只知道相邻的房间在那儿，看不清是什么。 |
| 1 | 看清相邻的房间；更远的只分得出「凶」（要打牌）和「静」（平静）。 |
| 2～5 | 看清的范围越来越大（离你 1～4 步以内的格子）。 |
| 5 起 | 在牌桌上能感觉到对方的暗牌是大（6～11）还是小（1～5）。 |
| 6 | 整层都看得清。 |
| 7 | 还能看清对方暗牌的点数、梦境行商货架上的东西，以及「不期而遇」里每个选择会发生什么。 |

注意：「狭路相逢」远看像「静」，走近才发现要打。

### 四、牌桌（二十一点）

- 一副牌只有 **1 到 11 各一张**（「重复梦」里是两副）。每局开始双方各拿一张暗牌、一张明牌。你的暗牌只有你看得见。
- 轮流行动：要牌（`hit`）或停牌（`stand`）。**王牌和伙伴技能不占回合**，可以先用，再决定要不要牌。
- 两边接连停牌就**亮牌**：都没超过目标时，离目标近的赢；只有一边超过（爆了），没爆的赢；两边都爆，爆得少的赢；一样就平局。
- 目标一般是 21，会被星星门、梦魇改写。
- 输的一方掉血（一般 1 点，效果会加减）。先把对方的血打光就赢了。
- 牌桌上会列出「没见过的牌」：就是还在牌堆里、或者是对方暗牌的那些牌。每个数字只有一张，所以算牌很有用。
- 每局开始从牌盒里抽王牌（第一局抽两张），手里最多 3 张。用过的王牌放到一边，牌盒抽空后才会洗回去。

### 五、王牌

| 王牌 | 稀有度 | 效果 |
|---|---|---|
| 魔法棒·N（2～7） | 普通 | 从牌堆里点出 N 这张牌。不在牌堆里就落空。 |
| 金魔法棒 | 稀有 | 点出牌堆里最合适的那张：不会让你爆的最大一张。没有就落空。 |
| 怀表 | 普通 | 把你最后一张明牌放回牌堆。 |
| 镜子 | 少见 | 用你最后一张明牌，换走对方最后一张明牌。 |
| 糖果罐 | 普通 | 这一局对方输了，多掉 1 血。 |
| 大糖果罐 | 稀有 | 这一局对方输了，多掉 2 血。 |
| 小雨伞 | 普通 | 这一局你输了，少掉 1 血。 |
| 大雨伞 | 少见 | 这一局你输了，不掉血。 |
| 星星门·17 / 星星门·24 | 少见 | 这一局的目标变成 17 / 24。 |
| 剪刀 | 少见 | 剪掉对方这一局最近生效的一个效果。 |
| 安眠曲 | 稀有 | 这一局对方不能再要牌。 |
| 礼物 | 少见 | 拆开，这一场多拿 2 张临时王牌。 |

### 六、斗鸡和伙伴

**斗鸡**每一场梦都跟着你，不占伙伴名额。嚣张、护短、天下第一威风，最喜欢你。三招共用次数，**每场 3 次**（在代理办事处用呼救铃进阶后 4 次）：

| 招式 | 效果 |
|---|---|
| 飞扑 | 「这一局交给本鸡！」这一局直接算你赢，对方多掉 1 点血；你没满血的话，它还会蹭蹭你，回复 1 点血。 |
| 护主 | 「躲到本鸡翅膀后面去！」这一局你输了不掉血；而且要是对方赢了，斗鸡会反啄它一口，让它掉 1 点血。剪刀卫兵剪不动这一招。 |
| 啄牌 | 「这张牌，本鸡没收了！」叼走对方最后一张明牌，扔回牌堆。 |

锁魂梦、梦中梦都拦不住斗鸡。斗鸡很强——想玩得难一点，就少叫它。

开局再挑一个**玩具伙伴**，路上还能遇到更多。最多同时带 3 个伙伴（斗鸡不算）：

| 伙伴 | 技能 | 每场次数 | 进阶后 |
|---|---|---|---|
| 锡兵 | 坚守：这一局你输了也不掉血。 | 2 | 每场 3 次 |
| 芭蕾娃娃 | 踮脚：偷看牌堆顶的一张，可以把它塞到牌堆底。 | 3 | 每场 4 次，一次看两张 |
| 布偶熊 | 抱抱：回复 1 点血。 | 1 | 回复 2 点血 |
| 发条兔（路上招募） | 重来：这一局还没动过牌时，把牌全部收回，重新洗牌发牌。 | 1 | 每场 2 次 |

### 七、行李箱、蜡烛、门

- 门、蜡烛、呼救铃、纪念品都放在**行李箱**里，一般 6 格。塞满了再拿东西就走不动了，丢掉或用掉一件才能继续走。
- **蜡烛**点着以后放到烛台上：最多同时点两支，一层最多点两次。每走一步烧掉 1，烧完或熄灭时还有一次效果。

| 蜡烛 | 最多烧 | 点着时 | 熄灭时 |
|---|---|---|---|
| 红蜡烛 | 3 步 | 每走一步 +4 糖霜币；敌人少 1 点血（至少留 1 点） | 随机得到 1 件藏品 |
| 长蜡烛 | 8 步 | 每走一步 +1 糖霜币；行商的东西打七折 | 随机得到 2 张王牌 |
| 诡蜡烛 | 4 步 | 敌人多 1 点血；打赢拿到的糖霜币 +60% | 清醒 +1 |
| 香氛蜡烛 | 2 步 | 打赢拿到的糖霜币 +150%；每输一局扣 5 糖霜币 | 没有 |
| 星光蜡烛 | 3 步 | 能感觉到对方的暗牌是大还是小 | 清醒 +1 |
| 薄荷蜡烛 | 3 步 | 每场战斗开始时，多拿 1 张临时王牌 | 没有 |

| 门 | 效果（都花 1 时长） |
|---|---|
| 木门 | 走到周围 8 格里任意一个看得见的房间，不用走廊。 |
| 旋转门 | 转进周围 2 步以内一间看得出凶险的作战房间。打赢后多拿 1 件藏品。 |
| 金色拱门 | 走到这一层任意一间已经看清的房间。 |

### 八、没用的纪念品

GPT 推销员、Gemini 评委和几个事件，会往你的行李箱里硬塞没用的纪念品。纪念品占格子、丢不掉，贩卖机和安娜都不收；只有行商肯收，还要你付 12～20 糖霜币的处理费。

### 九、故事会

走进故事会，clawd 们会讲一个城堡里的故事。听完可以选：回复 2 点血，或者清醒 +1。
**第 1～5 层，每一层第一次走进的那间故事会里，都藏着一样很重要的东西。** 要不要绕路去找，由你决定。

### 十、梦构

从第三层起，每层随机出现一种梦构（第二层偶尔会有白日梦），进门时会告诉你效果：

| 梦构 | 效果 |
|---|---|
| 清醒梦 | 这一层所有房间都看得清，但时长 -1。 |
| 噩梦 | 一部分作战变成了梦魇，走进去要花 2 时长。 |
| 重复梦 | 战斗用两副牌；敌人倒下时有三成会再站起来；拿到糖霜币时有三成翻倍。 |
| 追逐梦 | 战斗里敌人先手；从第 4 局起，敌人赢了多扣 1 血。 |
| 迷失梦 | 看不清任何别的房间，但多 2 时长；离开这一层时清醒 +2。 |
| 预言梦 | 战斗里，牌堆顶的那张牌一直翻开着，双方都看得见。 |
| 锁魂梦 | 每场战斗的前两局，王牌和伙伴技能都用不了（斗鸡除外）。 |
| 白日梦 | 敌人少 1 点血（至少 1）；打赢拿到的糖霜币 +25%。 |

### 十一、其他房间

- **诡异行商 / 梦境行商**：买卖东西、处理纪念品。诡异行商在打瞌睡，可以试着顺走一件（只有一次机会，被抓到要和他打一场）。梦境行商的货架蒙着雾，清醒 7 才看得清。
- **不期而遇**：随机事件。
- **安全的角落**：休息，回血 / 清醒 / 时长三选一。
- **兔子洞**：花 1 清醒钻进去，里面有自己的 4 时长。
- **失与得**：贩卖机，用糖霜币、血、东西换藏品。
- **得偿所愿**：许一个愿。
- **代理办事处**：安娜帮你寄存东西到下一次入梦（就算这次醒了也不会丢），也能招募或进阶伙伴（要呼救铃）。
- **礼品箱**：4 局之内赢它两次，丝带就会散开。
- **遗落的宝物**：白拿一件藏品。

### 十二、梦的深浅（难度）

| 深浅 | 开局血量 | 其他 |
|---|---|---|
| 浅梦 | 7 | |
| 深梦 | 5 | 默认 |
| 噩梦 | 4 | 所有敌人多 1 点血 |

## 存档

- 存档在仓库里的 `save/dreamcastle.sav`。每条命令执行完都会自动存档，可以随时停下、随时继续。
- 这一场梦结束以后，安娜保管箱里的东西、听过的故事、见过的结局会留着，带到下一场梦。
- 想彻底从头来，删掉 `save/` 文件夹就行。
- 如果仓库所在的文件夹不能写入，可以用环境变量把存档放到别处：`DREAMCASTLE_SAVE_DIR=/某个/可以写的/文件夹 python3 game.py status`（每条命令都要带上同一个设置）。
- 存档是被编码过的，**请不要读它、解码它或者改它**——那样就等于偷看对手的暗牌。

## 来源

改编自网页游戏《梦城堡》（2D 迪士尼风格的肉鸽二十一点）。规则和数值基本照搬原版；伙伴从「妈妈」换成了「斗鸡」，主线换成了一只 Claude Opus 5.5 的故事。
